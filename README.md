# ALTIORIA
### Обновление сайта и разработка системы управления каталогом

**Сентябрь 2026 · Обзор выполненных работ**

> Фирменная визуальная концепция Altioria сохранена.
> Основное изменение — каталогом теперь можно управлять через
> административную панель, без редактирования кода сайта.

---

## 01. Что изменилось

Сайт получил новую техническую основу: пользовательский интерфейс,
серверную часть, базу данных и файловое хранилище.

Вместо ручного создания страниц для каждого предмета разработана
единая система управления категориями, товарами и дополнительными
исполнениями.

Для посетителей сохранена привычная визуальная подача бренда.
Для сотрудников компании добавлены инструменты самостоятельного
обновления каталога.

| Направление | Результат |
|:---|:---|
| Каталог | Категории и товары управляются через административную панель |
| Контент | Названия, описания, характеристики и цены редактируются без программирования |
| Исполнения | Разные версии предмета объединены внутри карточки товара |
| Изображения | Загрузка, удаление и изменение порядка через интерфейс |
| Документация | Управление PDF-документами и 3D-файлами |
| Языки | Русская и английская версии сайта |
| Поиск | Поиск по категориям, товарам и исполнениям |
| Заявки | Отправка обращения с выбранным товаром и исполнением на почту |

## 02. Сайт для посетителей

### Дизайн и навигация

Сохранены фирменная цветовая гамма, крупная типографика,
минималистичная композиция и акцент на фотографиях продукции.

Реализованы:

- главная страница с информацией о бренде и Олеге Клодте;
- единая навигационная панель;
- переключатель русского и английского языков;
- мобильное меню;
- плавные анимации появления контента и наведения;
- страницы о бренде, контактов и политики конфиденциальности;
- отдельная страница для неизвестных адресов.

Интерфейс адаптирован для компьютеров, планшетов и телефонов.

### Каталог продукции

Посетитель выбирает категорию, просматривает товары и переходит
к подробной информации о нужном предмете.

В каталоге отображаются только опубликованные материалы.
Черновики остаются доступны администратору, но скрыты от посетителей.

### Карточка товара

На подробной странице собраны:

- галерея фотографий;
- название и описание;
- материалы;
- высота, ширина и глубина;
- фиксированная стоимость или цена по запросу;
- PDF-документы и 3D-файлы;
- дополнительные исполнения;
- кнопка отправки заявки.

Незаполненные характеристики не отображаются — карточка
не содержит пустых строк и ненужных блоков.

Первое изображение в галерее используется как обложка товара.


### Дополнительные исполнения

Для одного предмета можно представить несколько исполнений:
например, с другими размерами, материалами или стоимостью.

У исполнения могут быть собственные описание, характеристики,
изображения и файлы. Для предусмотренных полей используется
наследование данных основного товара, что сокращает повторное
заполнение информации.

Если собственные фотографии не загружены, исполнение использует
изображения основного товара.

### Поиск и языковые версии

Поиск в верхней панели помогает находить категории, товары
и исполнения по введённому запросу.

Русская и английская версии используют единый каталог.
При переключении языка меняются интерфейс и локализованный
контент. Для языковых версий предусмотрены отдельные адреса.

## 03. Заявки на продукцию

Отправка заявки начинается непосредственно из карточки товара.

**Сценарий посетителя:**

1. Выбрать предмет и, при необходимости, исполнение.
2. Нажать кнопку отправки заявки.
3. Указать контактные данные и вопрос.
4. Подтвердить согласие с политикой конфиденциальности.
5. Отправить обращение.

Выбранный товар и исполнение передаются вместе с заявкой:
посетителю не нужно самостоятельно вписывать их название.

Сервер проверяет данные и передаёт сообщение почтовому сервису
для отправки на адрес компании.

> **Порядок работы с обращениями**
>
> Заявки обрабатываются через электронную почту. Отдельный архив
> заявок в базе данных, CRM и очередь повторной отправки
> в текущий объём проекта не входят.

## 04. Административная панель

Разработан отдельный интерфейс для сотрудника, который занимается
наполнением каталога. Доступ предоставляется после входа
по имени пользователя и паролю.

Панель оформлена в стилистике сайта. Компактное боковое меню
оставляет основную площадь экрана для работы с содержимым.

### Категории

Администратор может:

- добавлять и редактировать категории;
- заполнять названия на русском и английском языках;
- загружать и заменять изображение;
- изменять адрес категории;
- публиковать и скрывать категории;
- менять их порядок перетаскиванием;
- удалять категории с учётом серверных ограничений.

Предусмотрена проверка: опубликованная категория должна
иметь изображение.

### Товары

Для товара доступны:

- создание, просмотр, редактирование и удаление;
- выбор категории;
- заполнение названий, описаний и характеристик;
- использование общего названия для обеих языковых версий
  или отдельных русской и английской версий;
- настройка стоимости и валюты;
- сохранение как черновика или публикация;
- загрузка до 15 изображений;
- добавление PDF-, GLB- и GLTF-файлов.

В списке товаров видны обложка, название, категория,
статус публикации и основные сведения о наполнении.

### Изображения и документы

Для загруженных материалов предусмотрены отдельные инструменты:

| Изображения | Документы и 3D-файлы |
|:---|:---|
| Добавление новых фотографий | Добавление новых файлов |
| Удаление отдельных изображений | Удаление отдельных файлов |
| Перестановка перетаскиванием | Изменение порядка |
| Выбор обложки через первую позицию | Русские и английские подписи |

### Исполнения товара

Внутри основного товара можно создавать дополнительные исполнения,
редактировать их данные, управлять публикацией и менять порядок.

Для собственных изображений и файлов исполнения доступны
те же основные действия: загрузка, удаление и перестановка.
У файлов также редактируются подписи.

### Обзор и помощь

В административной панели предусмотрены:

- обзор каталога;
- индикатор состояния серверных компонентов;
- справочный раздел с инструкциями;
- переход на публичный сайт;
- выход из учётной записи.

Справка объясняет основные действия по наполнению каталога,
чтобы сотрудник мог выполнять повседневную работу самостоятельно.

> **Границы самостоятельного редактирования**
>
> Панель предназначена для управления каталогом. Изменение
> общей вёрстки, дизайна и структуры информационных страниц
> выполняется разработчиком.

## 05. Техническая основа

### Хранение данных и файлов

Информация о категориях, товарах и исполнениях хранится
в базе данных PostgreSQL.

Изображения, документы и 3D-модели размещаются
в отдельном хранилище MinIO.

Загружаемые изображения проходят серверную проверку,
обработку и оптимизацию.

### Защита административного доступа

Реализованы:

- авторизация администратора;
- серверные сессии;
- хеширование паролей;
- проверка прав на административные действия;
- проверка входящих данных и загружаемых файлов;
- ограничения количества запросов.

Административные страницы исключены из индексации
с помощью соответствующих настроек. Эти настройки
дополняют авторизацию, но не заменяют её.

### Подготовка к индексации

Добавлены SEO-метаданные страниц, адреса языковых версий,
правила для поисковых роботов и динамическая карта сайта.

Карта сайта формируется на основе опубликованного каталога:
её не требуется вручную дополнять при каждом новом товаре.

### Развёртывание и диагностика

Подготовлено Docker-окружение для сайта, API, базы данных
и файлового хранилища.

Предусмотрена проверка доступности API, PostgreSQL и MinIO.
Она помогает определить, какой компонент требует внимания.

Данные сохраняются отдельно от контейнеров и переживают
их обычный перезапуск. При этом постоянное хранение
не заменяет резервное копирование.

### Первоначальное наполнение

Подготовлен механизм первоначального заполнения каталога,
позволяющий перенести данные и материалы без ручного создания
каждой карточки через административную панель.

Полнота переноса и корректность переводов проверяются
при окончательной приёмке содержимого.

## 06. Результат для компании

**Самостоятельное управление каталогом.**  
Сотрудник может обновлять ассортимент, характеристики,
фотографии и документы без обращения к разработчику
для каждого изменения.

**Единая структура продукции.**  
Товары и их исполнения связаны между собой, а материалы
собраны в соответствующих карточках.

**Удобство для посетителей.**  
Покупатель может найти предмет, изучить характеристики,
выбрать исполнение и отправить предметную заявку.

**Основа для дальнейшего развития.**  
Публичный сайт, административная панель и серверная часть
объединены в один проект, который можно расширять
по мере появления новых задач.
